Privacy Policy

Last updated: November 24, 2026

"Caught On Stream Uploader" is a private tool used only by the owner of the Caught On Stream YouTube channel to schedule and upload the channel's own Shorts.

What data the tool uses

  • It asks Google for permission to upload videos to the signed-in YouTube channel (the youtube.upload scope).
  • The sign-in token is stored only on the owner's own computer. It is never sent anywhere except to Google.
  • The tool only sends videos, titles, descriptions, tags and scheduled times that the owner prepared.

What the tool does not do

  • It does not collect, store, sell or share any personal data of viewers or other users.
  • It does not read, change or delete any other YouTube or Google data.
  • It uses no analytics, cookies or advertising.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The tool uses the YouTube API Services; see the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
